## 0.15.0-preview.3 · Google 授权连接可靠性

- 真实本机无凭据探测复现固定 token endpoint 间歇性建连超时，随后恢复。未更改系统 DNS、代理或 endpoint，未据此宣称 Google 审核通过。
- 点击 Google 三件套登录时先做最长8秒、无凭据的固定接口可达性检查；失败不开浏览器、不生成授权链接、不改旧连接，用户可稍后再点。检查通过只是当时可达，不保证后续授权成功。
- 交换授权仅在已知 DNS/建连失败、HTTP 请求尚未送出时补试一次，沿用原20秒总期限和固定 Google endpoint。HTTP响应、TLS、连接重置、取消及响应体错误不重试。每次重新核对绑定和配置。
- 前置配置检查失败不再误标网络；固定诊断分类不包含授权码、token、账户或原始错误。已保存授权继续保留，真实新授权完成仍须由本人核实。


## 0.15.0-preview.4 · 授权成功后直接接到来源启用

- 本人已确认 preview.3 新授权成功；日常 Host 回读为 `lastAttempt=saved`、三项已授权，尚未启用及读取。Google 审核仍是 UNDER_REVIEW。
- 成功卡片先显示「Google 已连接」和实际已启用数量，随后直接展示 Gmail、日历、Drive 的来源入口。重连和未验证页帮助收进次级区域；所有来源启用后改为可以提问。
- 新连接与失败重连仍在按钮前呈现数据用途、隐私与模型处理说明；正在授权优先于旧失败状态。界面没有自动启用、查询、重放授权或建立计划。
- 每次成功重连更换凭据代数，旧来源许可按原守卫失效，避免换账号后沿用旧读取范围。本轮只调整客户端，不改后端授权和家庭成员隔离。
