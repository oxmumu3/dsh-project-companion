# 逻辑项目与工作区

`0.20.0-preview.1` 本地候选。牛村木木山制作的社区插件；公开试用版本、Google 审核和手机投递分别记录，不由本页代表完成。

## 开始使用

电脑端可以直接与 Dot 对话。首次首页保留微信二维码：连接后可在手机交代任务和接收已开启的提醒，电脑和 Harness 仍需在线。

想让 Dot 帮你找出正在推进的项目，先点首页的工作区入口，选择一两个已在 Harness 登记的工作区并保存，再到「项目」点「整理这些工作区的项目」。保存范围只记住选择，不读取正文、不启动模型，也不开启自动扫描或推送。暂时不选择也能聊天，或写一句目标自行创建项目。

以后在「连接」的工作区入口添加或移除，使用同一个选择框。跨搜索和分页的选择会保留，保存前显示增加和移除的数量。新登记的工作区不会自动加入；目录或身份变化的旧授权需要显式清理。

## 三个概念

- 工作区是 Harness 登记的本地目录，是读取范围。
- 逻辑项目是持续推进的目标，可以跨工作区、跨会话；一个会话也可能包含多个目标。
- 会话是讨论和执行发生的地方，不会因为开了一个会话就自动成为一个项目。

整理只读取允许工作区的三个固定说明文件与有限的近期普通会话文本，使用当前 Harness 配置的模型分析。不会读取 `.env`、工具输出、附件内容、家庭成员会话、子 Agent 或继承的分叉历史。每次最多八个工作区、每个最多四个近期会话、合计最多四十条截断材料；后续显式整理轮转到其他工作区。未读取的范围保持未知。

## 看板与接着聊

看板分为「待我推进」「推进中」「等回复／确认」；无法确定的进展单独标明。新识别的项目是建议，需你保留或忽略；来源关联错了可以移到其他项目或移出。人工目标和约束不被模型覆盖；修改目标后旧进展标为待核对，保留依据。

点项目会在当前视野打开详情和专属原生对话，目标与约束会带入这条会话。各项目保留自己的草稿、附件与原生审批，返回后继续；不会静默填入屏幕外输入框，也不会自动发送。来源摘录、模型归纳、执行完成与业务验收分别呈现。

工作区授权管理的是 Dot 的自动识别读取范围，并不是 Harness 原生 Agent 的文件系统沙箱。原生对话中的工具执行仍受 Harness 自身设置和审批管理。撤回后停止新的识别读取，旧来源正文不再展示，进展标为待核对；已确认的目标、用户对话历史和此前已进入原生会话的内容不会被自动删除或“遗忘”。

本轮不改变既有微信绑定、Google/flomo/滴答账号授权、家庭成员权限或定时回顾安排。新增工作区范围不会自动扩大个人回顾、微信委托或主动推送的权限。
