## 已发现并修正的问题

- 旧摘要只给文件前 240 字，遗漏后半段阻塞。现将模型分析材料与手机短摘录分开，保留截断标记。
- 同一进度文件并存旧「待测」与新验收，导致首简报误读。固定来源整理为单一当前快照后，真实模型已正确总结；这一修正不能保证任意项目资料都准确。
- 冷启动时原绑定会话未加载，预览曾失败。现在仅在明确有效操作后恢复精确原会话；被动读取不恢复、不创建替代会话。
- 卸载并发曾可能提前移除只读守卫；已修复并增加真实插件生命周期回归。
- 网络失败后引导恢复、过期二维码显示、残留模块误判已安装等已修复并回归。

## 本地重现

默认开发环境为 Node.js 22.13+，安装依赖后运行：

```sh
npm install --ignore-scripts
npm test
npm run demo
```

默认测试依赖固定为官方 SDK `0.2.0-rc.2`。兼容矩阵另使用官方 App 对应的 `0.2.1-rc.2` SDK，并设置 `DSH_TEST_SDK_VERSION=0.2.1-rc.2`；这不是仅切换环境变量就会替换依赖。测试不会启动完整 Desktop、真实模型或常驻服务；演示使用合成材料与模拟发送。安装和启用请走[官方插件页面或本地安装器](install.md)。
