## 当前优先级（2026-10-22）

日常 App 已安装 `0.12.0-preview.3`，桥接保留 `0.11.1-dot.2`；精确包比对通过，安装后七个状态文件字节不变，来源授权、其他插件配置及启用列表保留。原生界面确认启用、一个组件运行；本版已真实读取滴答两项清单及 flomo 两条关键词结果，恢复两家在日常 Dot 的启用状态，Google 三来源及微信绑定保留，提醒0、项目日报关闭；实读后五个状态文件仍字节不变，项目观察记录和Context租约按预期变化，计划未变。本版本尚未公开发布，详见[验证记录](verification.md)。

两套 SDK 各 867 个唯一测试均已有通过证据：完整矩阵各 866 通过、1 项因未提供桥接夹具而跳过；随后使用精确桥接包补验，每套 11/11 通过，覆盖该跳过项。补验包含重复用例，不叠加为更多唯一测试；源码与合成回归不替代真人授权、手机收件或内容质量验收。

1. **补齐 Context 读取场景**：Google 三件套本人授权已完成，Gmail 搜索及限长正文、主日历七天空窗口、Drive 文件名搜索已真实通过；flomo 本版两条关键词搜索已验，使用者仍需 MAX。滴答保留 `tasks:read`，本版已在原生会话通过官方只读 API 读取两项清单，不扩大写权限，也不回退到要求额外权限的 MCP。支持清单、指定清单任务和指定任务读取，暂不支持全账号关键词搜索或自动翻页。滴答任务正文、Drive 文档正文、非空日程和长期令牌刷新仍待验。Google 仍为 External / Testing，仅登记账号可用，不能宣称任意公开新用户直接登录。
2. **微信体验与稳定性**：保留原绑定、提醒和日报机制，继续核对交办单份结果、缓存恢复不重派不复述、手机到达时间，以及长期和休眠恢复。安装与自动回归不能替代实际手机确认；所有手机收件和排版由用户本人确认，禁止微信客户端 UI 自动化。
3. **基于 Context 的主动价值**：现有项目记忆、项目变化卡、明确提醒和项目跟进继续使用。Google、滴答、flomo 仍仅在明确查询时读取，私人资料持续扫描、跨来源主动整理和推送尚未实现。下一步先明确来源、频率、打扰条件与停用方式，再接入可验证的计划；连接成功不会自动创建计划或长期记忆。
4. **资讯与对外交付**：AI 资讯已有独立定时能力和本次明示主题预览；92 个技术 RSS、最多 3 篇重点加 7 篇速览，不保证凑满十篇，也未核实“100 位 AI 作者”说法。继续验证选材质量、真实定时手机送达、持久兴趣和阅读反馈。GitHub 正式仓库已核对归属 oxmumu3；迁移不等于发布新版，具体版本及下载资产仍需单独核验。

Slack、Notion、云端 iCloud 与 iMessage 后置。陌生用户开箱、私人 Context 主动订阅、资讯手机闭环和长期运行仍分别保留验收状态。

## 历史优先级（2026-10-21，当时快照）

以下保留当时的版本、配置与待办判断，不代表当前安装或授权状态；当前状态以上节及[验证记录](verification.md)为准。

`0.11.0-preview.2` 是本地候选，原 App 仍运行 `0.10.0-preview.1`；源码回归、隔离宿主、真实模型、手机收件和公开发布分开核对，见[验证记录](verification.md)。本轮不迁移原计划、不扩大账号读取。

1. **Context 实际接通**：flomo/滴答已有官方账号授权入口，真实账号与有限读取待本人完成。Google Calendar 已有独立最小 OAuth/REST，但产品方 publisher 为空，普通登录仍准备中。先完成产品方应用身份和适用审核，再验明确时间窗；Gmail/Drive 逐源扩展，不把八个入口算作八个已接通账号。
2. **微信稳定好用**：先验准确原项目交办、单份结果、纯恢复不重派不复述，以及提醒到达时间；随后统一可理解的排队状态与低优先级通知预算。原 App 的另一项调试现场保留，本轮采用隔离官方宿主，不为升级中断现有任务。所有手机收件由用户本人确认，禁止微信客户端 UI 自动化。
3. **基于 context 的主动价值**：新增明确查询的项目变化卡，读取已关注项目三份固定文件与安全记忆，保留来源、角色、未知和截断。同可见资料静默，不代表全项目未变；独立水位按原会话/绑定/项目隔离。新卡未替换既有日报或主动跟进，先验内容质量，再由用户明确选择项目、频率和打扰条件后接入计划。
4. **资讯与日常汇报**：现有资讯支持本次明示主题预览，未保存兴趣或改变推送。下一步先预览确认少量兴趣，再考虑持久偏好、已读/无关反馈、跨推送去重与合并。92 个技术 RSS 不能宣传为已核实的 100 位 AI 作者；3＋7 是上限，不凑数。现有每日资讯任务保持原样。

Google 注册/真实授权、变化卡真实模型质量、新微信恢复、陌生用户开箱及休眠重连仍是验收缺口，不因自动测试通过而消失。Slack、Notion、云端 iCloud 与 iMessage 后置。
