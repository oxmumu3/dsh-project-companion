# 后续迭代

## 当前优先级（2026-10-28）

公开版仍为 [`0.14.1-preview.11`](https://github.com/oxmumu3/dsh-project-companion/releases/tag/v0.14.1-preview.11)。当前源码 `f57e5fb` / `0.15.0-preview.1` 已在日常官方 Harness `0.2.1-rc.3` 安装，精确配套 Family `0.2.0-preview.33-diary.6-dot.2`；不是新公开发行。公开完整包使用独立微信桥接，不自动升级或配置 Family。

本轮已补齐全部已登记项目的搜索分页与单次固定资料预览、共用 Owner 入口的明确五源查询、普通原生项目交办，以及用户指定范围的一次/间隔/每日跟进。电脑端冻结包在三套受支持 SDK 各 1280/1280、零失败零跳过；独立审读、隔离官方 Host、日常原生界面另有证据。原五源授权、家庭身份/权限/计划/消息与其他插件配置保留；重连清掉三个可选收发时间显示字段，不称所有状态字节完全不变。本轮未读取真人私人来源、未发微信、未建真实计划。

1. **完成一次手机验收**：核对当前版带来源简报、普通原生项目任务的一份结果、到时提醒和一次范围检查。旧版限定 flomo＋日历简报、受控 README 首行与提醒的本人收件记录继续保留，但不能替代 0.15 普通任务与主动跟进验收。所有手机收件和排版由本人确认，禁止微信客户端 UI 自动化。
2. **观察日常稳定与完整开箱**：继续核对审批、目标忙碌、失败/未知、取消、撤权、换绑、缓存恢复不重派，以及休眠和多日运行。三套 SDK 或一次隔离 Host 通过不等于新用户扫码开箱与长期稳定通过。
3. **跟进 Google 审核**：三项数据权限已正式提交，原生状态 `UNDER_REVIEW`；尚未批准、完成 CASA 或解除已知累计 100 个账号上限，不保证任意新账号可用。保留现有授权，不因查询状态重复提交审核或扩大 scope。flomo 仍需 MAX，滴答仍仅 `tasks:read`；指定清单任务已合成验证，任务正文仍待本人限定实读，历史清单元数据不冒充任务内容。
4. **收口范围与公开交付**：五源授权不等于订阅；只在明确项目、来源、范围、时间后检查，无变化静默。共用入口的任意自然语句、任意资源 ID、记忆增改与简报编号交办仍有限制，不能把独立 Dot 所有操作视为共享入口均支持。公开 0.15 前须核对配套 Family、真实资产、安装步骤及验收边界，再更新下载入口；不把本机候选包装成公开发行。
5. **继续验证使用价值**：有限资料是否能减少找信息和重新解释，交办结果是否能继续形成可靠的阻塞与下一步。AI 资讯保留独立的 92 个技术 RSS、最多 3 篇重点加 7 篇速览及明示定时，不凑十篇，不从私人资料自动推断兴趣。Slack、Notion、云端 iCloud 与 iMessage 后置。

当前操作见[快速开始](quickstart.md)与[个人资料闭环](context-loop.md)；旧版本实读与手机证明保留在[历史验证记录](verification.md)。
