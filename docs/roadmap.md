# 后续迭代

下列是规划中的功能，尚未包含在 `v0.4.0-preview.2`。当前能力和验证范围以[README](../README.md)与[验证记录](verification.md)为准。

## AI 高质量资讯日报

- 复用已有RSS资讯源及筛选、评分和摘要流程；来源与上游许可核实后再接入。
- 每天提供3篇重点详读＋7篇简短摘要，共10篇，保留标题、来源日期和原文链接；不足时说明实际数量，不凑数。
- 在微信中提供适合手机阅读的一份日报，避免详读与速览重复、避免重发。
- 支持明确开启、关闭与调整时间；随包提供不等于安装后自动启用日程。
- 使用用户的Harness模型和连接，不导入作者的账号或私有配置；继续遵守电脑在线与微信通道窗口限制。

接入后先验证原文与摘要质量，再分别核对定时触发、消息发送和手机实际收到。
