# 把个人资料接到项目下一步

`0.14.1-preview.11` 社区预览，作者牛村木木山。实际下载和用户验收以对应发布资产和验证记录为准。家庭助手共用微信入口的受控项目交办目前仅支持 README 首行的独立只读检查，不进入原生项目会话；以下一般项目会话交办仅描述独立 Dot 路径。

## 怎么用

以下示例适用于 Dot 独立微信入口。在绑定的微信对话告诉 Dot 一个具体目标和资料范围；家庭助手共用入口应按实际开放的来源使用，目前不支持 Gmail 或 Drive：

> 为「我的项目」准备明天的客户沟通。结合主日历未来一天的安排、Gmail 最近三天主题含“项目名称”的邮件，各看三条，再结合这个项目的资料，给我一份带来源的简报。先不要执行或设置推送。

Dot 会保留这次范围，整理进展、阻塞和建议下一步。你可以接着说：

> 把刚才第二项交给这个项目：只读检查相关材料，整理三个需要我决定的问题，完成后回我一次。

这项交办关联原简报和已有执行账本。结果仍由原微信通道回传；重复说同一项不会再次派工。只有明确未派发时，用户再次要求才会重试，最多三次；结果不明时不盲目重发。若目标有多个会话，Dot 按会话名称询问；不要求用户查内部 ID。

需要跟进时再说：

> 每隔一小时检查这份简报的资料范围和执行结果，只有新变化、阻塞或需要我决定的事才告诉我。

也支持“一分钟后只检查一次”。没有明确时间或频次时不默认创建计划。暂停、取消跟进和忘记简报范围分别处理，原本已交给项目的任务不会被伪装成已撤销。

## 本轮组合了什么

| 环节 | 复用能力 | 新增衔接 |
| --- | --- | --- |
| 资料 | 既有 Google、滴答、flomo 读取器与权限检查 | 每来源独立的有界查询，不混用搜索参数 |
| 简报 | 现有宿主模型、摘要校验、项目资料和记忆 | 目标、编号、来源引用、版本与同一事项身份 |
| 微信交办 | 原生 Coordinator、TaskResults、pan17 维护桥接 | 事项关联 jobId，持久去重及提交前的权限复核 |
| 主动跟进 | 已保留许可的 proactive 调度器 | 只运行保存的资料范围；内容没变保持安静 |
| 页面 | V2 工作台和原会话草稿 | “结合资料排下一步”入口；修改频率保留原资料范围 |

没有另建微信通道、连接器、模型服务或定时系统。nanobot、Hermes、OpenClaw 的连续任务思路作为设计参考，没有复制其实现；既有 vendored YOLO/proactive 和微信桥接版权继续保留在第三方说明中。

## 范围与真实状态

- 当前每个原会话、已关注项目保留一份活动范围，最多四项查询、每项最多三条资料。一次最多九个有依据的简报条目；不承诺扫完整账号。主日历不等于全部日历，缺失或截断一直明确标出。
- 连接账号只表示可按需使用。只有用户选定目标、来源范围并明确安排检查，才会形成对应的自动读取。改目标、改范围或重新连接账号会使旧计划不能沿用新权限。
- 摘要、范围、引用与少量摘录存在本机 Harness 的 `project_companion_context_loop` 存储域。完整邮件/文档响应与凭据不会被复制进该域。模型处理资料沿用用户的 Harness 模型；回复微信仍经过已绑定的通道。
- 持久编号是简报的引用，不是新的正式待办系统。滴答状态以源系统为准。助手执行回复仍待验收；通道接收不等于手机收到。
- 执行结果最多取 600 字供后续提炼阻塞和下一步，明确是助手来源并可能截断。已有结果正文由原交办账本回传一次，跟进不会再创建第二个结果 outbox。
- 同样的资料缺失不会反复推送，也不会被当作已解决；主动查看时仍能看到缺项。授权失效会停下相应检查，临时网络失败保留“未知”。
- 本轮主路径为已绑定微信的原会话。无绑定的原生会话可整理资料，交办结果关联与主动送达不作同等保证。
- AI 资讯日报仍使用原来的独立入口与频次，不默认从私人资料推断阅读偏好，也不把公开资讯重复塞进项目简报。

## 本地候选安装

候选包独立于公开 preview4，精确支持 Harness `0.2.0-rc.2`、`0.2.1-rc.2` 与 `0.2.1-rc.3`。保存并正常退出 Harness 后，在解压的候选目录运行 `node scripts/install.mjs --bundle-dir . --install`，或使用同目录 `Install.command`。安装器保留已有兼容微信桥接和绑定，检测到运行中的宿主会停止；不使用版本豁免。

## 实测时确认

电脑端先通过合成账号和 SDK 检查，之后再在真实微信一次验证：有限资料简报是否有用、编号交办是否准确、结果是否仅一份、一次检查是否只提示新变化、取消后是否不再推送。旧版的收件记录不代替本候选验收。
