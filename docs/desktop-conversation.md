# 电脑端对话与全局入口

本文对应本地开发候选 0.19.0-preview.1，公开下载仍以 README 的已发布版本为准。候选的安装、真实界面和手机验收分别记录，不能以源码存在代替完成。

Dot 的电脑入口分为两层：左侧「DSH Dot」打开完整工作台；Harness 内的 Dot 小入口用于随时展开对话。小入口覆盖 Harness 自身的页面，不是跨 macOS 所有应用的系统悬浮窗。

首页从白色对话区开始。点击「开始对话」创建本地原生会话；已有旧会话通过「继续上次对话」明确选择，旧验收历史不会自动占住首屏。创建会话不发送消息、不查询私人来源、不创建提醒或计划。保存的会话指针只是本机历史候选，使用前仍向宿主核对，不能当作微信 Owner 身份或私人资料授权。

首页和悬浮面板复用同一会话。切换时先释放可编辑视图，再由下一处接管，持续保留草稿和附件引用；浮层收起不销毁会话。已完成的纯文字回合可收拢为最近一问一答，完整历史可以展开。执行中、待审批、出错、工具结果及复杂内容继续显示宿主完整原生视图，原生输入、发送、权限和审批链均保留。

首次且已确认尚未连接微信时，首页直接显示当前可用二维码与过期/刷新状态。扫码不是开启所有推送。已经绑定家庭微信、通道暂时离线或身份尚无法核实时，显示原连接的恢复入口，不生成新绑定、不要求重扫。微信未连接也能先在电脑开始。

「需要你关注」只投影当前 Owner、绑定代数和授权范围内已经保存的事项，最多五项。未确认归属的旧记录不会被混入；来源只呈现安全元数据，不扩读正文。保存的个人回顾和 AI 日报安排展示原时区及状态；保存安排不代表下一轮实际运行或手机收到。资料暂时无法核实时统一给出恢复提示，不以空白冒充无事发生。

共用家庭管家的微信入口仍保持原来身份、绑定代际和家人权限。它的结果记录可以展示在工作台，但不会用 `family_owner_*` 冒充原生桌面会话。桌面会话可用也不代表五源资料自动获得授权；每项资料操作继续核对原有启用范围。

## 连接状态

连接页区分：保存了账号授权、启用了来源、当前授权流程正在进行，以及实际读取是否成功。flomo、滴答的登录回调只在当前宿主存活、流程有效时接收；过期后短时间保留清晰的重新连接提示，并拒绝交换旧 code。宿主已退出或重启时，旧端口无法继续服务，需要从当前 Dot 发起新流程，不刷新旧回调页。

已有凭据不会因一次失败的重连被清除。已保存凭据和未到期只是本机状态，不承诺供应商端没有撤权。公开 RSS 日报使用已确认的微信 Owner 路由，不因无关私人来源不可用而被挡住；私人资料读取仍保留各自授权检查。
