# 第一次使用 DSH Dot

这是牛村木木山制作的社区项目助理，为已有官方 DeepSeek Harness 增加项目与微信流程，非官方产品。本页面向 `0.12.0-preview.4`，安装入口见[安装说明](install.md)。本版增加 Google 授权前用途说明和普通点击登录的加密存储。Google 已切为 External / In production，无需测试白名单，但正式权限验证仍待完成，有未验证提示与累计 100 个账号上限；本人确认的另一账号已在本版隔离 Host 重启后完成三项各一项读取，不代表任意账号可用；flomo 需要 MAX。历史有限读取与本版源码、宿主、手机验收分别见[验证记录](https://github.com/oxmumu3/dsh-project-companion/blob/d389852e3aebfab061325d72b8286ba40de319ee/docs/verification.md)。

1. 先按[安装说明](install.md)准备受支持的官方 Harness。从[0.12.0-preview.4 发布页](https://github.com/oxmumu3/dsh-project-companion/releases/tag/v0.12.0-preview.4)下载同版本完整包。解压完整目录，保存工作并正常退出 Harness，再双击 `Install.command`。没有 Harness 时入口只指引安装官方应用，不会自动装好一整套；模型登录与配置由你本人完成。
2. 打开 Harness，从左侧打开「DSH Dot」，首次使用时主按钮是「连接微信」。全新或空白会话按宿主规则显示首次引导；已有工作对话不会被抢走。
3. 已连接微信直接继续。首次连接时扫码确认，再从微信发一句「你好」。扫码登录和建立会话是两步，页面会显示当前状态；此页不会重置已有连接。
4. 先选择一个关注项目，点「保存关注并预览简报」。最多可关注五个；已有关注保留，之后可在会话里取消。列表来自 Harness 已知项目；没有项目时先在 Harness 添加一个项目，再回此页刷新。不会扫描整台电脑或读取全部历史。
5. 点「生成首份简报并回到微信」。它只在真实绑定的原微信会话中处理一次只读简报。页面分别显示已提交、正在整理和已生成；必要时点「刷新简报状态」。只有在手机实际看见后，才点「我已在微信收到这份简报」。重复进入不会重发已接收的首简报；请求被接收、简报已生成都不代表手机已经收到。
6. 日常在首页输入事情，点击「开始对话」把草稿放进原生 Dot 会话；再由你发送。若原生会话已有草稿，会完整保留，并提示你处理已有输入。
7. 点击项目打开详情：概况看已保存的目标、阻塞、下一步；「记住的事」可纠正或忘记具体记录；来源页签显示证据。已有概况不等于项目变化卡；候选里可在 Dot 会话明确说“看看这个项目变了什么、有哪些阻塞和下一步”。新卡不自动替换原计划，真实模型质量仍待验。执行回复只表示项目会话完成了这一轮，业务结果由你验收。
8. 从项目或执行回复选择「查看或安排跟进」，先查现有计划，再选择未来七天内的一次时间或明确频率。核对项目、时间和微信通道后单独确认。页面显示下一次检查，可随时取消；无实质新变化保持安静。

## 连接 Google、笔记与清单

打开「DSH Dot → 连接与设置」，先阅读 Google 卡片中的资料用途说明与隐私链接，再点击「同意并连接 Google」，用自己的账号完成官方页面的授权。读取的资料会进入 Harness 会话及你配置的模型；通过微信查询时，回复也经过微信。请仅使用符合 Google 数据用途要求、不会将这些资料用于通用 AI 训练的模型服务。

三件套只申请邮件、日历事件和云盘只读权限；不需要你创建 Cloud 项目或复制凭据。授权期间 Dot 会检查状态，回来后按需要启用 Gmail、日历、Drive；只同意一部分时，其余来源仍保持未授权。当前受众不再要求逐个加入测试名单，但 Google 仍可能显示未验证提示或账号限制。已用本人确认的另一账号，在本版隔离 Host 重启后完成 Gmail 搜索、非空 primary 日历和 Drive 搜索各一项；未核对该账号的 Cloud 名单身份，不把一次成功推广到所有账号。日常 App 升级及完整新用户开箱仍待验收。

普通三件套和单独日历的新授权在本机使用 Keychain 密钥与 AES-256-GCM 密文保存。已有这两类明文授权只在明确查询、需要获取 Google 令牌前受控迁移；只刷新状态不会迁移。无法读取钥匙串或密文验证失败时会提示处理，不会明文降级；重新登录可用新授权替换旧连接。高级手填凭据、会话内容和历史备份不在这项加密补强范围。
第一次可以直接问：「查一下未来 24 小时有什么安排」「找一下关于面试的邮件」「在云盘找一下项目计划」。默认不会全盘扫描，也不会因为登录就自动发日报。文档、幻灯片与表格按指定文件读取，表格需给一个小范围。已有单独日历连接继续使用原账号。

flomo、滴答清单在下方分别点击登录即可；flomo 需要 MAX。滴答普通连接只申请 `tasks:read`，可读取清单、指定清单中的任务或指定任务，暂不支持全账号关键词搜索和自动翻页。授权过期可重新连接，停用则停止 Dot 读取；从高级设置清除本机授权，与在服务商账号里撤销许可是两件事。私人资料持续扫描与主动推送尚未实现。你读到的内容可能进入 Harness 当前会话和所配置的模型，微信回复还会经过微信通道。

先用一个项目核对摘要是否有用，再逐步增加。已有绑定的冷启动、预览和重复入口在旧候选有本机实测；旧版手机收件不能替代本轮新包的准确交办、单结果与恢复验收。全新用户扫码开箱仍待验证。安装问题见[安装说明](install.md)。

首份简报后，可以交办一条明确的小任务：「继续示例项目，只读检查 README 的验收项，不要改文件。」目标接收后等待对应执行回复；有多个候选会话时按友好标题选择。查询进度只读，不会重新派工。恢复缓存时说：「继续收取刚才缓存的回复就好，不要重新执行任务，也不要新增提醒。」新版单结果与恢复防重复仍需真实验收。

想试一次，可以说：「一分钟后只检查这个项目一次，告诉我变化、卡点和下一步。」没有实质新变化时可静默结束，做完不会留下周期计划。

要收固定日报，可以说：「每天早上九点发我关注项目的日报。」想按变化跟进，可以说：「每两小时检查写作项目，有值得关注的事再告诉我。」两者是独立计划，首次引导都不会默认开启。可随时说「取消每日汇报」或「取消这个项目的主动跟进」。

电脑与 Harness 需要在线。微信连续主动消息受 10 条交互窗口限制，正常发一条微信消息后恢复；发送回执不等于手机收到。请在手机上自行确认收件和显示效果，不使用微信客户端 UI 自动化。当前各层证据与剩余限制见[验证记录](https://github.com/oxmumu3/dsh-project-companion/blob/d389852e3aebfab061325d72b8286ba40de319ee/docs/verification.md)。
