# 第一次使用 DSH Dot

这是牛村木木山制作的社区项目助理，使用官方 DeepSeek Harness 和社区微信桥接，非官方产品。本页描述 `0.9.0-preview.2` 本机候选；下方公开下载仍为 `0.6.0-preview.1`，旧版界面与本文可能不同。

1. [下载安装包](https://github.com/piggy00544/dsh-project-companion/releases/download/v0.6.0-preview.1/dsh-dot-0.6.0-preview.1-macos.zip)，解压完整目录，双击 `Install.command`。已有 Harness 时先保存工作并正常退出；没有时按入口指引安装官方应用，再回车继续。模型登录与配置由你本人完成。
2. 打开 Harness，从左侧打开「DSH Dot」，首次使用时主按钮是「连接微信」。全新或空白会话按宿主规则显示首次引导；已有工作对话不会被抢走。
3. 已连接微信直接继续。首次连接时扫码确认，再从微信发一句「你好」。扫码登录和建立会话是两步，页面会显示当前状态；此页不会重置已有连接。
4. 选择最多五个关注项目，点「保存关注并预览简报」。已有关注保留，之后可在会话里取消。列表来自 Harness 已知项目，不扫描整台电脑或读取全部历史。
5. 点「生成首份简报并回到微信」。它只在真实绑定的原微信会话中处理一次只读简报。页面分别显示已提交、正在整理和已生成；必要时点「刷新简报状态」。只有在手机实际看见后，才点「我已在微信收到这份简报」。重复进入不会重发已接收的首简报；请求被接收、简报已生成都不代表手机已经收到。
6. 日常在首页输入事情，点击「开始对话」把草稿放进原生 Dot 会话；再由你发送。若原生会话已有草稿，会完整保留，并提示你处理已有输入。
7. 点击项目打开详情：概况看已有目标、阻塞、下一步；「记住的事」可纠正或忘记具体记录；来源页签显示证据。执行回复只表示项目会话完成了这一轮，业务结果由你验收。
8. 从项目或执行回复选择「查看或安排跟进」，先查现有计划，再选择未来七天内的一次时间或明确频率。核对项目、时间和微信通道后单独确认。页面显示下一次检查，可随时取消；无实质新变化保持安静。

先用一个项目核对摘要是否有用，再逐步增加。已有绑定的冷启动、预览和重复入口已在本机实测；全新用户扫码开箱仍待验证。安装问题见[安装说明](install.md)。

以后直接说：「看看写作项目今天变了什么」「记住这个项目的决定」「继续插件项目，先检查验收项」。只有你明确交代执行时才派工；查询进度和主动检查只读。

想试一次，可以说：「一分钟后只检查这个项目一次，告诉我变化、卡点和下一步。」没有实质新变化时可静默结束，做完不会留下周期计划。

要收固定日报，可以说：「每天早上九点发我关注项目的日报。」想按变化跟进，可以说：「每两小时检查写作项目，有值得关注的事再告诉我。」两者是独立计划，首次引导都不会默认开启。可随时说「取消每日汇报」或「取消这个项目的主动跟进」。

电脑与 Harness 需要在线。微信连续主动消息受 10 条交互窗口限制，正常发一条微信消息后恢复；发送回执不等于手机收到。请在手机上自行确认收件和显示效果，不使用微信客户端 UI 自动化。当前各层证据与剩余限制见[验证记录](verification.md)。
