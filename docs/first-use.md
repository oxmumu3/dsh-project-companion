# 第一次使用 DSH Dot

本页对应 `0.20.0-preview.4` 公开预览。先按[安装说明](install.md)安装，重开 Harness，打开左侧「DSH Dot」。

## 先把 Dot 带到微信

首次首页直接展示当前二维码。由本人扫码，再从微信发一句「你好」；已有兼容绑定直接沿用，不重新配对。连接后可以在手机交代任务、收结果和已开启的提醒。微信暂未连接也能先在电脑聊。

已有共用家庭微信入口时，保留原对话和独立家人权限；本包不自动安装或升级Family，也不为新用户建立Owner委托。普通读者按独立Dot流程使用。

## 只选一两个工作区开始

想让Dot帮你整理项目，点首页工作区入口，选择一两个Harness已登记的本地工作区，保存后再点「整理这些工作区的项目」。后续在「连接」增减，新增工作区不会自动加入。

保存选择只记住范围，不读正文、不调用模型、不建计划；明确整理时才有限读取固定说明与近期会话。没有合适工作区时，也能先写一个目标自己创建项目。

工作区是目录和读取范围；项目是持续推进的目标，可以跨工作区、跨会话。新识别的是建议，保留或忽略由你决定；目标和约束可纠正。新增逻辑项目不会自动扩大私人回顾范围。

## 从事情本身继续

在首页白色输入框说目标；已有旧会话由你明确选择继续。点项目会在当前视野打开详情和原生对话，草稿、附件和原生审批保留，不会把内容静默塞到屏幕外的输入框，也不会自动发送。

要从微信派发执行时说清Harness已登记工作区名称，例如：

> 把这个任务交给 我的工作区：读取本项目的 README.md，用三句话说明用途，完成后把结果回给我。

把“我的工作区”换成真实名称；目标不明确、忙碌或待审批时会说明。已接收不等于已完成，通道发送不等于手机收到。看板逻辑项目可先在其专属桌面对话讨论。

## 有需要，再连接资料和开启回顾

在「连接」点击 Google、flomo 或滴答的官方登录，由本人同意后再启用所需来源。Google 权限审核中、可能有未验证提示与累计100账号限制；flomo需要MAX。授权、启用和读取不是同一步，登录不会自动开始扫描。

先预览：

> 预览一份个人回顾，使用我在电脑启用的资料和已关注项目，不建立计划。

希望定期收到，再明确说：

> 每天09:00、每周一09:00，使用我在电脑启用的资料和已关注项目做个人回顾，有风险或临期事项告诉我。

> 开启个人回顾的工作时段主动关注。

要AI日报，先说「AI日报关注：Agent产品、插件生态、增长实践」，再说「每天09:10发AI日报」。保存兴趣不会开启推送。未说时区时按电脑时区确认；可随时暂停、取消。新增账号或工作区不静默扩大旧计划。

自动回顾仍为实验能力，flomo近期读取和历史自然模型输出失败仍在排查，不能把保存计划当成每天成功送达。电脑和Harness需在线；多日与休眠恢复尚未完整验收。详见[个人回顾](personal-review.md)、[逻辑项目](logical-projects.md)、[验证记录](verification.md)。
