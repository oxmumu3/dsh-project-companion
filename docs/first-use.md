# 第一次使用 DSH Dot

这是牛村木木山维护的社区项目，为已有 DeepSeek Harness 增加个人项目助理，并非官方产品。

1. 按[安装说明](install.md)先安装并打开一次官方 Desktop 完成初始化，正常退出后安装 Dot 与配套桥接。
2. 再打开 Harness，确认自己的模型可用、两个插件启用，从侧栏打开「DSH Dot」。按实际界面完成微信绑定；首次扫码及微信消息由本人操作。
3. 选择已在 Harness 添加的项目，先尝试一份带来源的简报；如需 Gmail、日历、Drive、flomo 或滴答，在「连接与设置」按需授权并启用来源。
4. 在微信提出明确问题、任务或提醒，并核对实际回复。连接不会自动扫描；定时跟进需要明确设定范围和频率。

现有家庭助手共用微信入口属于额外配置；该入口尚不开放 Gmail 或 Drive，请按界面显示和实际可用来源使用。该入口的受控项目交办目前仅为独立读取 README 首行，不会进入原项目会话。Google 最近已知仍有未验证提示及账号限制，flomo 官方授权可能需要 MAX。首次新用户从头安装、扫码到手机收到仍需完整验证。
