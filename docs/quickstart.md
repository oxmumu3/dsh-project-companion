# 快速开始

先按[安装说明](install.md)完成官方 Desktop 初始化、Dot 安装和微信绑定，再选择一个已添加到 Harness 的项目。你可以直接说：

- 「看看这个项目现在的进展和阻塞。」
- 「从 flomo 搜索 DeepSeek 最多两条，再看看未来一天的日历，结合这个项目给我一份简报。」
- 「两分钟后提醒我检查结果。」
- 「先预览一期 AI 资讯日报，不发微信。」

资料连接、授权和计划都是按需开启；电脑、Harness 与网络需要保持可用。自然语言交办的实际能力取决于入口与权限：家庭助手共用入口当前仅支持 README 首行独立只读检查，不等同原生项目会话执行。更多边界见[首次使用](first-use.md)和[资料连接](context-sources.md)。
