# 快速开始

公开下载为 `0.6.0-preview.1`；源码 `0.10.0-preview.1` 候选增加微信投递恢复与账号登录授权。先按[安装说明](install.md)安装，再在 Harness 设置中打开「DeepSeek Dot」：已有微信连接直接沿用；首次连接扫码后，在微信发一句「你好」，选择关注项目并生成首份简报。完整动线见[首次使用](first-use.md)。

## 在电脑上查看项目总览

点击 Harness 左侧固定的「DeepSeek Dot」。选择已关注项目，查看固定文件的更新时间、来源摘录和近期对话；下方可查看当前 Dot 会话最近的交办、活动提醒与项目日报状态。资料未能读取时显示未确认，不据此判断项目已完成或计划已关闭。

「打开 Dot 会话」回到现有绑定会话；「打开项目会话」仅导航，不提交任务。同项目有多个已知会话时，由你明确选择。通过「管理关注与连接」打开原有引导与账号配置；关闭后可以刷新项目总览。

打开或刷新总览只读已关注项目的固定本地文件、已观察记录和已有账本，不连接私人云端来源，不恢复冷会话、不启动模型、不发微信，也不创建或修改计划。当前界面不直接修改项目记忆；继续在 Dot 会话中用自然语言纠正和维护记忆。

## 了解与记住项目

先说：「看看我有哪些本地项目。」

再说：「关注写作系统，看看今天变了什么、哪些还没验证。」助手按名称查找项目，只读有限来源。项目重名时会澄清；无需复制路径或记内部编号。

也可以说：「记住这个项目的目标是……」「上次做过哪些决定？」记忆保留来源与时间，是项目上下文笔记，不自动创建正式待办。来源中的建议不构成执行授权。

## 明确交办

「继续插件项目，检查 README 里还有哪些验收项，先不要改文件。」

目标忙碌时不打断；同项目有多段真实工作会话时按名称澄清。接收任务与执行完成分别报告，执行回复回到原微信对话。你可以再问：「刚才交办的事怎么样了？」绑定变化或来源不可用时保留状态，不改投其他对话，也不自动重派不确定的任务。

## 提醒与固定日报

- 「两分钟后提醒我检查结果。」
- 「每天早上九点发我关注项目的日报。」
- 「取消每日汇报，其他提醒保留。」
- 「先暂停助理。」

相对时间由服务按当前时钟计算，未指定时使用电脑时区，并用文字确认。电脑和 Harness 需要在线；暂停、排队或失败会说明，取消不能撤回已交给通道的消息。

## 按变化只读跟进

先试一次：「一分钟后只检查这个项目一次，告诉我变化、卡点和下一步。」

它先确认安排并结束当前回合，到期后独立只读检查，完成后不留周期计划。可问「刚才那次检查怎么样了」或说「取消刚才那次检查」。微信来源按原绑定回复；明确未绑定微信的本项目原生会话可只在本机接收结果。

想持续跟进，再说：「每两小时看看这个项目，有值得关注的事再告诉我。」没有实质新变化时可静默结束。可说「取消这个项目的主动跟进」「暂停助理」「恢复助理」。安装和状态查询不会默认创建计划；自主回合不能改文件或派工。

固定日报与按变化跟进是两种独立计划，不需要同时开启。周期检查采用电脑时区 23:00–08:00 免打扰；明确请求的一次性检查可在此期间执行。

## 先知道的限制

微信连续主动消息有 10 条交互窗口；正常发一条微信消息后恢复，不需记额外管理命令。通道发出与手机收到分别核对，请在手机上确认显示。

个人资料连接是可选项，不影响先使用本地项目助理与公开 AI 资讯。0.6 已加入 Gmail、Google 日历、Drive、Docs、Sheets、Slides、滴答和 flomo 的按需只读入口，flomo和滴答可点击登录授权后逐项启用，Google仍需本人配置开发者客户端；真实账号读取仍待验收。Google 需要官方 MCP 预览资格与自己的 Cloud 客户端，flomo 需要 MAX，完整步骤见[连接说明](context-sources.md)。Slack、Notion、云端 iCloud 和 iMessage 尚未接入。新用户开箱、长期运行与休眠重连仍待验证。源码回归、真实模型与手机收件分别列在[验证记录](verification.md)，开发排障另见[开发命令](developer-commands.md)。

## 0.10 候选的微信恢复

明确尚未送出的连接故障由桥接按1/5/15秒最多自动补发三轮，不绕过微信连续10条窗口；已经发出但无法确认的结果保持待恢复，避免盲目重复。电脑离线或休眠不保证准点。

需要手动恢复时说：「继续收取刚才缓存的回复就好，不要重新执行任务，也不要新增提醒。」这条纯恢复请求直接由通道处理，不再启动模型复述；同时包含新问题的消息仍正常交给助手。
