# 快速开始

本页面向 `0.12.0-preview.4`，固定下载入口为[本版发布页](https://github.com/oxmumu3/dsh-project-companion/releases/tag/v0.12.0-preview.4)。这是已有官方 Harness 的增强包：按[安装说明](install.md)完成安装与模型配置，从左侧打开「DSH Dot」，沿用或建立微信会话，先选一个项目生成简报。完整动线见[首次使用](first-use.md)。

Google 为受限公众预览，无需测试白名单，但权限未验证，可能有未验证提示与累计 100 个账号上限；本人确认的另一账号已在本版隔离 Host 重启后完成三项各一项读取；名单未独立回读，不能推广为任意账号可用。普通 Google 点击登录使用本版新增的本机加密存储，flomo 需要 MAX。本人历史读取与本版验证分别见[验证记录](https://github.com/oxmumu3/dsh-project-companion/blob/d389852e3aebfab061325d72b8286ba40de319ee/docs/verification.md)。

## 在电脑上查看项目总览

点击 Harness 左侧固定的「DSH Dot」。首页写下要交代的事，点击「开始对话」将草稿带入原有 Dot 会话，再由你发送；已有草稿会保留。选择已关注项目，可看已保存的目标、阻塞、下一步与来源，以及当前 Dot 会话的执行回复、活动提醒和项目日报状态。资料未能读取时显示未确认，不据此判断项目已完成或计划已关闭。

「打开 Dot 会话」回到现有绑定会话；「打开项目会话」仅导航，不提交任务。同项目有多个已知会话时，由你明确选择。通过「管理关注与连接」打开原有引导与账号配置；关闭后可以刷新项目总览。

打开或刷新总览只读已关注项目的固定本地文件、已观察记录和已有账本，不连接私人云端来源、不恢复冷会话、不启动模型、不发微信，也不创建或修改计划。在项目详情的「记住的事」可明确纠正或确认忘记记录；也可继续在 Dot 会话里用自然语言维护。候选新增明确查询的项目变化卡：说“看看这个项目变了什么、有哪些阻塞和下一步”，会读三份固定文件与安全记忆，保留来源及未知；同可见资料未变时不重复正文。它不替换已有计划，真实模型质量仍待验。

## 了解与记住项目

先说：「看看我有哪些本地项目。」

再说：「关注写作系统，看看今天变了什么、哪些还没验证。」助手按名称查找项目，只读有限来源。项目重名时会澄清；无需复制路径或记内部编号。

也可以说：「记住这个项目的目标是……」「上次做过哪些决定？」记忆保留来源与时间，是项目上下文笔记，不自动创建正式待办。来源中的建议不构成执行授权。

## 明确交办

「继续插件项目，检查 README 里还有哪些验收项，先不要改文件。」

目标忙碌时不打断；同项目有多段会话时，优先沿用同一原对话、当前微信绑定下最近成功交办的准确目标；证明不足才按名称澄清。目标忙碌时不会改投其他会话。接收任务与执行完成分别报告，执行回复回到原微信对话。你可以再问：「刚才交办的事怎么样了？」绑定变化或来源不可用时保留状态，不改投其他对话，也不自动重派不确定的任务。

## 提醒与固定日报

- 「两分钟后提醒我检查结果。」
- 「每天早上九点发我关注项目的日报。」
- 「取消每日汇报，其他提醒保留。」
- 「先暂停助理。」

相对时间由服务按当前时钟计算，未指定时使用电脑时区，并用文字确认。电脑和 Harness 需要在线；暂停、排队或失败会说明，取消不能撤回已交给通道的消息。

## 按变化只读跟进

先试一次：「一分钟后只检查这个项目一次，告诉我变化、卡点和下一步。」

它先确认安排并结束当前回合，到期后独立只读检查，完成后不留周期计划。可问「刚才那次检查怎么样了」或说「取消刚才那次检查」。微信来源按原绑定回复；明确未绑定微信的本项目原生会话可只在本机接收结果。

想持续跟进，再说：「每两小时看看这个项目，有值得关注的事再告诉我。」没有实质新变化时可静默结束。可说「取消这个项目的主动跟进」「暂停助理」「恢复助理」。安装和状态查询不会默认创建计划；自主回合不能改文件或派工。

固定日报与按变化跟进是两种独立计划，不需要同时开启。周期检查采用电脑时区 23:00–08:00 免打扰；明确请求的一次性检查可在此期间执行。

## 先知道的限制

微信连续主动消息有 10 条交互窗口；正常发一条微信消息后恢复，不需记额外管理命令。通道发出与手机收到分别核对，请在手机上确认显示。

个人资料连接是可选项，不影响先使用本地项目助理与公开 AI 资讯。此前日常版已真实读取 flomo 搜索与滴答清单，flomo 需要 MAX；滴答普通账号只申请 `tasks:read`，不支持全账号关键词搜索或自动翻页。Google 三件套普通入口无需填写 Token 或开发者配置；先读用途说明和隐私链接，再点「同意并连接 Google」。当前为受限公众预览，无需测试白名单，但仍有未验证提示与累计 100 个账号上限；此前日常 `0.12.0-preview.1` 已有本人授权与有限读取记录；本版另在隔离 Host 重启后验证了本人确认的另一账号，Gmail 搜索、非空 primary 日历、Drive 搜索各 limit1，未读完整邮件、附件或 Drive 正文，未调用模型、发送微信或建计划。本版普通 Google 授权使用 Keychain 密钥 + AES-256-GCM 存储；旧普通记录在明确查询前迁移，状态刷新不迁移。高级手填凭据与历史备份不在该保证范围。滴答任务正文、Drive 正文、日常 App 与手机上的非空日程呈现、长期令牌刷新仍未验，私人资料持续扫描和主动推送尚未实现。完整边界见[连接说明](context-sources.md)。Slack、Notion、云端 iCloud 和 iMessage 尚未接入。新用户开箱、长期运行与休眠重连仍待验证；旧版手机收件记录不代表本轮新包已通过。源码回归、真实模型与手机收件分别列在[验证记录](https://github.com/oxmumu3/dsh-project-companion/blob/d389852e3aebfab061325d72b8286ba40de319ee/docs/verification.md)，开发排障另见[开发命令](https://github.com/oxmumu3/dsh-project-companion/blob/d389852e3aebfab061325d72b8286ba40de319ee/docs/developer-commands.md)。

## 微信恢复

明确尚未送出的连接故障由桥接按1/5/15秒最多自动补发三轮，不绕过微信连续10条窗口；已经发出但无法确认的结果保持待恢复，避免盲目重复。电脑离线或休眠不保证准点。

需要手动恢复时说：「继续收取刚才缓存的回复就好，不要重新执行任务，也不要新增提醒。」当前代码将这种纯恢复请求直接交给通道，避免再启动模型复述；同时包含新问题的消息仍正常交给助手。这条新版路径已做电脑端回归，真实手机恢复与单结果仍待验收，不能拿旧版收件记录代替。

可以说：「先预览一期与 DeepSeek 插件、创作者生态相关的 AI 资讯，不要发微信或新建计划。」关注点只用于这一次筛选和摘要，不保存为以后偏好，不自动读取项目或私人账号。当前定时日报仍沿用原设置，不能用本次预览替代订阅修改。
