# 在微信继续当前任务

手机端能停、能续、能答，靠的是两个插件都在：家庭助手（`@oxmumu3/dsh-family-assistant`）提供手机入口，Dot 注册任务范围。只装 Dot 时这部分不启用，电脑端功能不受影响；`health` 的「手机控制」一行会说明当前是哪种情况。


直接告诉 Dot 要继续哪个项目、做什么；沿用原生会话和原结果记录。

- 问“任务状态”或“现在到哪了”：查询当前处理对象，不新建执行。
- 说“停一下”：请求停止当前任务，并清掉同一会话尚未执行的本人输入。保存或已发出的内容会保留。
- 多项任务并行时，回复“任务状态：项目名称”或“停止：项目名称”。
- 收到补充问题后，回复选项编号或文字；多个问题用显示的短码和题号。宿主转入稍后回答时，原短码仍在本次手机等待窗口内有效，回答接回原问题。
- 权限操作要按消息明确回复“同意本次 短码”或“拒绝 短码”；不会把“好”当批准，也不会记为永久批准。

窗口最长10分钟。过期、重绑、离线、停止、卸载或执行身份不明时，不自动继续。会话混入其他来源时停止自动回传，避免把不同任务内容串在一起。结果仍走原回流和验收机制；接口接受与手机实收分别记录。
