## 实现

- 今天／项目／记忆／连接四页：自然语言主入口、真实执行回复摘录、需要关注的状态、下一次跟进；首次使用显著连接微信。
- 原生会话草稿使用官方接口，由本人发送；保留已有原生输入，成功交接才清理匹配的首页草稿。
- 项目记忆保留来源，可纠正或忘记；关闭可继续、保留或放弃。草稿按项目、记录、微信绑定隔离；原文被其他入口修改时展示冲突，旧草稿不会静默消失。
- 跟进展示实际单次／周期状态与时间；核对后设置，可关闭。仅看页面不会启动模型、建计划或发消息。
- 连接页区分授权、启用、提问；Google、flomo、滴答复用原通路。未授权时不假装已读资料。暖纸浅色与配对深色样式跟随宿主，375px 窄屏无横向溢出。
- 绑定变更使旧控件失效；来源启停在队列等待后再次核对绑定。读取投影不调用会改写状态的恢复路径。

## 验收

- Node 22.22.0，SDK `0.2.0-rc.2` 和 `0.2.1-rc.2` 完整矩阵各 **943/943**，零失败、零跳过。每套串行、128 MiB；测试副本与最终运行代码匹配。
- 独立契约／代码审读通过。首轮矩阵保留两处失败历史：严格绑定夹具缺失（仅修测试、生产保护未放松）、既有资讯 CPU 测试超时；最终完整重跑均通过，未改变性能阈值。
- 官方隔离 Host 已安装候选，Dot 启用运行；76 个运行文件与冻结包字节一致。验证四页、浅深色、375px、记忆草稿保留／保存读回、未来单次安排／取消和取消后空闹钟、解绑后入口变化。使用虚构阅读项目，微信桥接发送组件禁用，无真实发送、私人账号或模型请求。
- 已观察到原生会话打开、首页草稿成功清除。隔离会话没有模型与完整工作区配置，原生输入框文字显示尚待日常会话验证；API 与卸载顺序已有自动回归，不把它写成完整模型执行验收。
