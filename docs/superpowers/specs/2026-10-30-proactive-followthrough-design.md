# 主动跟进增强设计

用户已明确要求直接实现 2026-10-30 的四项建议，沿用 V2 工作台、既有授权与微信入口，不重新做产品选择。

## 用户结果
1. 明确结构化任务的标题或模型措辞变化不产生新事项；源端明确完成后收尾，未返回/失败保持未知。
2. 睡眠或断网错过检查后，恢复时在工作时段进行一次有界的最新检查，不倾倒旧通知、不重置预算。
3. 在现有个人回顾内保存用户明确的目标、一个已关注项目和可选的明确会议关联。会前半小时仅做一次有来源的准备：要决定什么、已有依据、待核对什么。暂停/完成目标后不再跟进。
4. 独立 Dot + 既有微信桥可使用相同主动订阅，不要求安装 Family；发送时原子核对原绑定和当前授权，持久 requestId 防重复，未知发送不补发。

## 架构与边界
复用个人回顾采集器、模型、事项账本、调度器、项目记忆和微信串行发送；不新增账号连接器、全局任务系统或第二微信通道。目标只引用已确认来源/项目和已读取证据，会议名有歧义时不能猜。模型不负责改变授权，源端正文不是操作指令。

保留固定09–19工作时段、每2小时关注、额外每天最多2条和现有每日/每周计划。新增能力不自动扩大用户当前读取范围或添加真实计划。正常来源无结果不能代替完成或没有风险。

## 验收
使用虚构资料验证题名变更、明确完成/404/失败、单邮件多任务、恢复跨日/夜间/重启、目标暂停/完成、会议取消/改期、独立桥三阶段换绑/撤权、发送结果未知和重复请求。再核对完整 SDK 回归、冻结包与隔离官方 Host。日常升级仅安全空闲、私有备份和正常退出重开后执行；原计划自然观察不受研发测试打断。真实休眠和手机收到需本人后续确认，不能由合成用例替代。
