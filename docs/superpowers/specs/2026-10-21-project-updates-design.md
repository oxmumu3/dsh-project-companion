# 已授权范围：有来源的项目变化卡

用户已明确继续完善DSH Dot并收口今晚的可演示预览，交付计划要求变化/阻塞/下一步和第二次无变化静默。本实现不扩大私人账户、自动化、UI改版或推送范围。

## 选择

采用已有已关注项目的固定文件、结构化项目记忆，加本插件自己的最小检查水位。不扫描全盘或历史，不另起Agent会话。只用宿主现有模型提炼；模型无法使用时明确未完成，不以模拟摘要冒充。保持旧digest与既有定时计划，新增明确查询的project_update工具action；现有主动跟进是否复用新action，必须证明原scope/owner/quiet守卫和不重投，不能自动修改任何已有计划。

## 合同

- 每次明确一个当前已关注项目；读取现有固定资料与memory.inspect安全投影，保留source role、时间、截断。未知或拒绝读取不推断完成，助手说完成不等同验收。
- 使用createProjectUpdateService与小型宿主模型adapter；模型材料只包含本次固定范围和上次有界结论/指纹，无秘密配置或外部账号。
- 模型输出changes/blockers/nextSteps，每项最多3条、每条最多200字符、至少一个输入中真实sourceId；来源索引由插件生成，不信模型自造URL/path。可以选择基于来源的原文摘录；推断/建议必须标明。拒未知ID、超界输出、角色混淆、模型直接命令或虚构verified状态。
- 本插件独立有界store记录origin session +当前binding+精确project root的最后成功水位及有界结果，不修改项目文件/记忆或正式待办，不迁移旧绑定、不增加timer。失败/取消/换绑/取消关注不推进水位。
- 指纹忽略纯mtime/generatedAt；相同可见资料直接返回quiet不调用模型。可见范围与全项目无变化分开。所有来源失败返回unavailable而非quiet，不宣称任务完成。来源由可读变缺失/截断必须保留unknown，不能吞掉阻塞。
- async读取/model/store前后复查scope、暂停、当前会话/绑定/关注，最后紧靠保存/返回再核。仅显式请求可建立检查水位；不发微信、不派工、不建立计划。
- 返回一份适合微信的文本，有变化、阻塞、下一步与来源/时间，最多3200字符；首次为首次概览。无变化可quiet，不能返回旧正文导致再次转发。

## 验证与完成边界

TDD覆盖首次概览→同内容不同mtime静默→真实阻塞变化→来源丢失未知→变更/纠正记忆后恢复；跨绑定/跨项目/取消关注/暂停/关闭/模型失败/存储失败/异步竞态无泄露或重复。独立host工具接线、SDK矩阵、可恢复记忆实跑、包审计分别核对；模拟SDK不等于真实模型、手机或安装。原App报错现场/Lab/既有15篇资讯任务不操作。
