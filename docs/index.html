从了解项目，到把事情推进

一个入口，接着做。

01

在微信了解项目

选择已经添加到 Harness 的本地项目，查看带来源和更新时间的进展、阻塞与下一步。保留有限项目记忆，之后继续聊。

「看看写作项目今天变了什么。」

02

交办，等执行回复

独立 Dot 入口可将明确任务交给对应项目的可用会话，接收与完成分别呈现。家庭助手共用入口需另行配置 Owner 委托，完整安装包不会安装或升级家庭助手。

「检查这个项目的 README，先别改文件。」

03

按需要提醒与跟进

安排一次提醒、项目日报或只读检查，也可以暂停和取消。AI 资讯日报支持最多三篇重点与七篇速览，保留原文链接。

「明早九点发我关注项目的简报。」

04

把资料接到问题上

Gmail 只读权限用于查找和汇总你选择的邮件，日历只读权限用于查询主日历的指定时间段，Drive 只读权限用于检索和读取你指定的文件。授权后自行启用来源，再提出具体查询；相关内容可能传给你配置的模型，微信回答会经过微信通道。

flomo、滴答清单也支持官方登录。

Google 当前仍有未验证提示与累计 100 个账号上限；flomo 需要 MAX。家庭助手共用入口按另行配置的 Owner 授权范围读取。连接不会自动开启私人资料持续扫描或推送。

开始使用

装到你的 Harness，
连到你的微信。

适配已验证的官方 Harness 0.2.0-rc.2、0.2.1-rc.2 与 0.2.1-rc.3。完整 macOS 安装包包含 Dot 与兼容微信桥接；已有绑定是否保留请以实际安装结果核对。

  1. 先初始化官方 Harness。安装官方 Desktop 后先打开一次完成初始化与模型配置，保存工作并正常退出。
  2. 安装并连接微信。下载完整包并按安装步骤操作，重新打开 Harness；核对插件运行，首次连接由本人扫码。
  3. 先选一个项目。选择一两个工作区后明确整理项目，在看板或电脑对话继续，再按需连接资料、开启回顾。安装不默认创建计划。

使用前了解

电脑、Harness、网络和相关会话需要保持可用。退出、休眠及微信通道限制会影响提醒和送达。本版自然主动推送验收、独立新用户首次扫码到收件、连续多日与休眠重连、Windows 整合安装仍待验证。

flomo近期读取与历史自然模型失败仍在排查，自动回顾为实验能力。微信连接复用社区桥接；发送回执不等于手机实际收到。对外部账号的授权和手机确认由本人完成。

你的资料会去哪里

维护者不经营集中代存 Google 令牌或私人资料的 Dot 服务器。本版普通 Google 点击登录将刷新授权加密保存在本机配置中，密钥保存在 macOS Keychain；读取结果可能进入会话、宿主记录、配置的模型服务，以及微信回复通道。

这项存储补强不覆盖高级手填凭据、会话内容或历史备份，也不代表资料始终只留在电脑。启用 Google 前，请先了解存储与传递方式，并使用符合 Google 数据用途要求的模型服务。
